We welcome contributions from the community!

## Development Setup

1. **Fork and Clone**:
   ```bash
   git clone https://github.com/merge-guardian-platform/merge-guardian.git
   ```
2. **Setup Dependencies**:
   ```bash
   go mod download
   ```
3. **Run Tests**:
   ```bash
   go test ./...
   ```

## Submission Rules

1. **Open an Issue**: Discuss major changes before starting work.
2. **Focus on Tests**: Every new feature or bug fix must include corresponding unit tests.
3. **Follow Syntax**: Use `go fmt` to ensure standard Go formatting.
4. **Merge Strategy**: We prefer squash merges with descriptive commit messages.

## Code of Conduct
Please be respectful and professional in all interactions within the community.
